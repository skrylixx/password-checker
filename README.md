# password-checker
A beginner-friendly Python program to check password strength and provide improvement tips.


Welcome to the **Password Checker**! This Python program allows users to check the strength of their passwords and provides helpful tips to make them stronger.

## Features

- Checks for password length
- Detects presence of:
  - Uppercase letters
  - Numbers
  - Special characters
- Categorizes passwords into:
  - Weak
  - Poor
  - Fair
  - Medium
  - Perfect & Strong
- Provides tips to improve password strength

## How to Use

1. Clone the repository or download the script.
2. Run the Python file:

```bash
python password_checker.py
````

3. Enter your password when prompted.
4. The program will display:

   * Password strength
   * Tips for improvement
